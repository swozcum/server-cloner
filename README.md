# 🚀 Sunucu Kopyalama (Server Copy)

Discord sunucusunu tüm ayarlarıyla (roller, kategoriler, kanallar, izinler, ikon, banner) başka bir sunucuya kopyalayan Electron masaüstü aracıdır.

## ✨ Özellikler

| Özellik | Açıklama |
|---------|----------|
| 🎭 Rol Aktarımı | Renk, izin ve hiyerarşiyle birlikte kopyalanır |
| 📂 Kategori Aktarımı | Kanal izinleri dahil |
| 💬 Kanal Aktarımı | Text/voice/news/stage kanalları, konu, yavaş mod, bitrate |
| 🖼️ Sunucu Ayarları | İsim, ikon, banner |
| ✏️ İsim Değiştirme | Kaynak isimlerdeki metni otomatik değiştirir |
| 📊 Canlı İlerleme | Safha safha ilerleme çubuğu ve loglar |
| 🔔 Bildirim | İşlem bitince Windows bildirimi |

## 🛠️ Kurulum

```bash
npm install
```

Kurulum tamamlandıktan sonra `başlat.bat`'ı çalıştırman yeterli.

## 📖 Kullanım

1. **Hesap Tokeni** alanına kopyalama yetkisi olan hesabın tokenini yaz.
2. **Kaynak Sunucu ID** alanına kopyalanacak sunucunun ID'sini yaz.
3. **Hedef Sunucu ID** alanına boş sunucunun ID'sini yaz.
4. (Opsiyonel) İsim değiştirmek için eski/yeni isim yaz.
5. **Kopyalamayı Başlat** butonuna bas.

> ⚠️ Hedef sunucudaki tüm kanal ve roller silinir.
